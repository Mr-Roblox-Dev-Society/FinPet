# Сброс и удаление профиля

Все данные хранятся только локально в Room (`finny_pet.db`).

## Способы

### 1. Настройки ребёнка

Настройки → **Сбросить тестовый профиль** → подтверждение **Да, удалить**.  
Очищаются профиль, журнал трат, мета. Приложение возвращается к выбору роли.

### 2. Раздел для взрослого

Барьер (пример или удержание) → **Сбросить / удалить профиль** → подтверждение.

### 3. Системно

Настройки Android → Приложения → Питомец Финни → Хранилище → Очистить данные.  
Либо удаление приложения.

## Что не восстанавливается

После сброса код ребёнка, баланс, гардероб и прогресс обучения безвозвратно удаляются с устройства. Резервных копий в облаке нет.
