# Известные ограничения прототипа

1. Визуал питомца упрощён (emoji + градиент), без полноценного 2D/3D рига «Говорящий Том».
2. Звуковые эффекты не включены в сборку v1.0.0 (есть только флаг).
3. Один профиль на устройство (id=1).
4. Родительский доступ работает на том же устройстве (код не синхронизируется в облако).
5. Сезон по календарю устройства; без сети часовой пояс — системный.
6. Подписанный release APK собирается издателем своим ключом.
7. Нет автоматических UI espresso-сценариев на все экраны (есть юнит-тесты экономики + ручные TC).
8. Анимация пульса простая; сложные motion scenes не реализованы.
9. Публикация в RuStore во время хакатона **не входит** в объём (есть только материалы).
10. ИИ / облако / Big Data отсутствуют намеренно.
