# Тест-кейсы

## TC-01 Первый запуск ребёнка
**Шаги:** установить → «Я ребёнок» → онбординг → выбрать питомца → имя → Начать.  
**Ожидание:** главный экран, баланс 500, код в прогрессе/настройках, шкалы видны.

## TC-02 Ежедневный вход
**Шаги:** «Забрать вход». Повторно нажать.  
**Ожидание:** +100 один раз за период; повтор — сообщение «уже получено».

## TC-03 План бюджета
**Шаги:** план 200/100/100 при 400 → подтвердить; план 300/100/100 при 400.  
**Ожидание:** первый ок, остаток 0; второй отклонён.

## TC-04 Работа и болезнь
**Шаги:** снизить энергию сном/работой до 0 или выставить болезнь лекарством-обратно (через недоедание в демо).  
**Ожидание:** при болезни/0 энергии работа недоступна с объяснением.

## TC-05 Еда и лекарство
**Шаги:** купить еду; довести до болезни; купить лекарство.  
**Ожидание:** −100/+голод; лекарство −1000, прогресс заданий не сброшен.

## TC-06 Налог в демо
**Шаги:** включить демо → пройти до периода 5 → завершить период.  
**Ожидание:** списание 150 или болезнь при нехватке средств + объяснение.

## TC-07 Накопления
**Шаги:** перевод 50; попытка 40; снятие без подтверждения; с подтверждением.  
**Ожидание:** 40 отклонено; preview срока; после подтверждения баланс↑ копилка↓.

## TC-08 Одежда
**Шаги:** купить базу футболки; купить цвет; надеть.  
**Ожидание:** база обязательная категория; цвет +10 радости; аватар меняет градиент.

## TC-09 Задание и урок
**Шаги:** пройти t_pay_1; урок budget с верными ответами.  
**Ожидание:** объяснение всегда; за идеальный тест +25.

## TC-10 Родитель
**Шаги:** код из настроек → вход взрослого / барьер → кабинет.  
**Ожидание:** прогресс и траты; сброс с подтверждением очищает профиль.

## TC-11 Сохранение
**Шаги:** изменить баланс → убить процесс → открыть снова.  
**Ожидание:** данные на месте.

## TC-12 Юнит-тесты
**Шаги:** `./gradlew test`  
**Ожидание:** GameEconomyTest и ChildCodeGeneratorTest зелёные.
