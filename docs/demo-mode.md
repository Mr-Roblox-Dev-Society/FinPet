# Демонстрационный режим

## Как включить

1. Создайте профиль ребёнка.
2. Главный экран → **Настройки**.
3. Нажмите **Включить демо-режим**.

## Что меняется

| Параметр | Поведение |
|----------|-----------|
| Периоды | Можно завершать подряд кнопкой «Завершить период (демо)» |
| Ожидание реального времени | Нет |
| Сезон | Переключается вручную кнопками времён года в настройках |
| Налог | 150 монет на **5-м периоде** |
| Сброс | «Сбросить тестовый профиль» возвращает к выбору роли |

## Рекомендуемый демо-сценарий

1. Онбординг → лисёнок «Финни».
2. Забрать вход (+100).
3. Составить план бюджета.
4. Лёгкая работа → еда → отложить 50.
5. Задание «Обязательное или желание?».
6. Купить базу одежды текущего сезона / сменить сезон.
7. Повторить периоды до 5-го → показать налог.
8. Положить зверушку спать (это займёт 8 настоящих часов)
9. Дождаться восстановления энергии за сон.
10. Сбросить профиль.


## ВАЖНО! В демо режиме можно закончить режим работы досрочно (что рекомендуется тестировать в демо-сценарии), но нельзя завершить режим сна досрочно! Просьба тестировать функцию сна последней (сон продлится 8 часов, после чего с зверушкой снова можно будет взаимодействовать)
