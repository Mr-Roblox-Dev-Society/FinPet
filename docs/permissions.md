# Разрешения Android и состав данных

## Разрешения

В `AndroidManifest.xml` **не запрошены** опасные и сетевые разрешения:

- нет `INTERNET`
- нет `ACCESS_NETWORK_STATE`
- нет геолокации, камеры, контактов, микрофона, SMS

Приложению достаточно стандартного доступа к собственному внутреннему хранилищу (Room), который не требует runtime-permission.

## Состав локальных данных

| Данные | Содержимое | Передача наружу |
|--------|------------|-----------------|
| Профиль | код, имя питомца, балансы, шкалы, прогресс, гардероб | Нет |
| Журнал трат | период, название, сумма, категория | Нет |
| Контент | JSON в assets (только чтение) | Нет |

**Не собираются:** ФИО ребёнка/родителя, телефон, email, фото, точная геолокация, рекламные ID.

Имя питомца — вымышленный игровой никнейм, вводится локально, не является идентификатором личности в смысле обязательной регистрации.
