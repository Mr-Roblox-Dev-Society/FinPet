# Экономика: формулы и правила

Валюта только внутриигровая. Реализация: `GameEconomy` + `GameInteractor`.

## Константы

| Параметр | Значение |
|----------|----------|
| Старт | 500 |
| Ежедневный вход | +100 (1 раз за период) |
| Хороший тест | +25 (все ответы верны) |
| Работа EASY/MEDIUM/HARD | +100 / +200 / +300; энергия −20/−35/−50; голод −20/−30/−45 |
| Еда | −100, голод +50 |
| Лекарство | −1000, снимает болезнь |
| Налог | −150 на 5-м дне недели / 5-м демо-периоде |
| Развлечение | −100, радость +50 |
| Сон | энергия +60, бесплатно |
| Мин. перевод в копилку | 50 |
| Дизайн одежды | цена варианта, радость +10 разово |
| Цели | 1000 / 1500 / 2000 |

## Баланс

```
balance' = balance + incomes - expenses
incomes ∈ {daily_login, work_pay, test_reward, savings_withdraw}
expenses ∈ {food, medicine, tax, entertainment, toys, clothing_base, clothing_variant, savings_deposit}
```

Нельзя уйти в минус: покупка отклоняется с объяснением.

## План бюджета

`mandatory + optional + savings ≤ balance`  
Остаток = `balance − total`. После периода сравнение с `PeriodFact`.

## Здоровье

- Без еды > 1 периода (демо-аналог 24ч) → болезнь.
- Без развлечения ≥ 7 периодов → болезнь.
- Болезнь: работа запрещена, доступен вход 100/день.
- Лечение не обнуляет прогресс (задания, стадия, копилка).

## Сезонная одежда

Базовый комплект обязателен (лето 240, осень 380, зима 700, весна 330).  
Доп. дизайны/цвета — необязательные, хранятся в гардеробе, меняют вид на главном экране.

## Стадии питомца

Взвешенный score:

- 40% выполнение обязательных относительно плана;
- 30% близость факта к плану;
- 30% регулярность накоплений.

≥0.75 взрослый, ≥0.45 подросток, иначе малыш. Причина показывается текстом.

## Оценка срока цели

```
periods = ceil((target - saved) / avgTransfer)
```
при `avgTransfer = 50` по умолчанию в UI.
