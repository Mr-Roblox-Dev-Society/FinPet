# UX / UI

## Цели дизайна

- Яркий мультяшный стиль, понятный детям 7–11.
- Один понятный хаб (главный экран), короткие фразы.
- Обратная связь после каждого важного действия: что изменилось и что делать дальше.
- Без стыда и запугивания.

## Визуальные решения

- Палитра: небо / солнце / трава / коралл на тёплом фоне (`FinnyTheme`) — не «фиолетовый AI-дефолт».
- Крупный аватар питомца с пульс-анимацией (отключаемой).
- Градиент аватара отражает надетую одежду.
- Кнопки высота 52 dp (≥ 48), скругление 16 dp.
- Карточки обратной связи — единственные «карточки» как контейнер взаимодействия/результата.

## Навигация

- Главный экран → разделы списком крупных кнопок.
- Единый TopAppBar с «Назад».
- Родительский раздел за барьером (пример или удержание).

## Тексты

- Термины «бюджет», «обязательные расходы», «накопления» объясняются в онбординге и уроках.
- Негативный исход → путь восстановления (работа, план, отказ от желания).

## Демонстрация

Отдельный явный CTA «Завершить период (демо)» на главном экране при включённом демо.
