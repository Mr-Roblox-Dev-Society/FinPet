# Безопасность и защита ребёнка

## Принципы

1. Нет аккаунтов и обязательного сбора персональных данных.
2. Нет реальных платежей, банковских данных, рекламы, подписок, IAP.
3. Нет внешних ссылок в детском UI.
4. Нет чатов и соцсети.
5. Родительский раздел за барьером (арифметика / удержание).
6. Сброс данных — только с подтверждением.
7. `allowBackup=false` снижает риск утечки через облачный бэкап Android.
8. Секреты (keystore) не хранятся в репозитории.
9. ProGuard включён для release.

## Соответствие при публикации

При выкладке в RuStore издатель подтверждает возрастную маркировку, отсутствие сбора ПДн сверх необходимого и соответствие правилам защиты детей. Черновик карточки — `rustore.md`.

## Угрозы прототипа

Локальный код ребёнка не является криптостойкой авторизацией: он защищает от случайного входа ребёнка в кабинет, а не от злоумышленника с физическим доступом к разблокированному устройству.
