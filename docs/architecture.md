# Архитектура «Питомец Финни»

## Функциональная архитектура

```
┌─────────────────────────────────────────────────────────┐
│                     Пользователь                         │
│              (ребёнок / взрослый)                        │
└───────────────┬─────────────────────┬───────────────────┘
                │                     │
        ┌───────▼───────┐     ┌───────▼───────┐
        │  Игровой цикл │     │ Родительский  │
        │  питомца      │     │ обзор         │
        └───────┬───────┘     └───────┬───────┘
                │                     │
   ┌────────────┼────────────┬────────┘
   ▼            ▼            ▼
 Бюджет     Экономика    Обучение
 Накопления Покупки      Задания/уроки
 Состояние  Одежда       Обратная связь
```

### Основные функции

| Функция | Описание |
|---------|----------|
| Онбординг и роли | Выбор ребёнок/взрослый, код доступа, знакомство с 3 типами решений |
| Жизнь питомца | Голод, энергия, радость, болезнь, стадии роста |
| Экономика | Доходы (вход, работа, тест), расходы, налог, сезонная одежда |
| Планирование | Распределение бюджета до периода, сравнение план/факт |
| Накопления | Цели 1000/1500/2000, перевод ≥50, снятие с подтверждением |
| Обучение | 6 заданий + 3 урока с тестами |
| Демо | 5 периодов, ручной сезон, налог на 5-м |
| Родитель | Барьер, прогресс, траты, сброс |

## Компонентная архитектура (Clean + MVVM)

```
ui (Compose + ViewModel)
        │
        ▼
domain (GameInteractor, GameEconomy, models, repository interfaces)
        │
        ├── content (JSON assets → ContentRepository)
        └── data (Room → ProfileRepositoryImpl)
```

- **UI** не содержит формул экономики.
- **GameEconomy** — чистые функции без Android.
- **GameInteractor** — сценарии (купить, работать, период…).
- **ContentRepository** — единственная точка чтения учебных JSON.
- **ProfileRepository** — персистентность профиля и лога трат.

## Навигация

`FinnyNavHost` + маршруты в `Routes`. Главный экран — хаб ко всем разделам. Единообразный `TopAppBar` с «Назад».

## Потоки данных

`Room Flow` → `StateFlow` в `FinnyViewModel` → Compose. Действия возвращают `ActionFeedback` (баланс, копилка, состояние, объяснение, следующий шаг).

## Офлайн

Сервер не используется. Интернет-разрешений нет. Основной цикл полностью локальный.
