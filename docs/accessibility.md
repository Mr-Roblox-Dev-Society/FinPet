# Доступность

| Настройка / приём | Реализация |
|-------------------|------------|
| Кнопки ≥ 48×48 dp | Высота 52 dp у `FinnyPrimaryButton` / Secondary |
| Текст ≥ 16 sp | `bodyLarge` / `bodyMedium` 16 sp в теме |
| Цвет не единственный канал | Подписи «обязательно / по желанию», текст обратной связи, иконки/emoji |
| contentDescription | Semantics на кнопках и шкалах |
| Отключение анимаций | Флаг `animationsEnabled` (пульсация аватара) |
| Отключение звука | Флаг `soundEnabled` (готовность к аудио в след. версии) |
| Критичное не только звуком | Все события — текстом в FeedbackCard |
| Подтверждение опасных действий | Сброс профиля в 2 шага; снятие из копилки с preview |
| Единообразный возврат | TopAppBar Back |
| Портрет, от 360 dp | Manifest portrait; layout на fillMaxWidth |
| Простой язык | Короткие предложения, без жаргона без пояснения |
