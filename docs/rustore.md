## Краткое описание (до ~80–120 символов)

Играй с питомцем и учись планировать бюджет — без настоящих денег и рекламы.

## Полное описание

«Питомец Финни» — бесплатное просветительское приложение для детей 7–11 лет.

Вместе с ярким питомцем ребёнок:

• учится составлять простой бюджет (обязательные расходы, желания, накопления);  
• зарабатывает игровую валюту работой и заданиями;  
• кормит питомца, следит за энергией и радостью;  
• копит на цели и видит последствия решений;  
• проходит короткие уроки финансовой грамотности.

Важные границы:

• только игровые монеты — никаких реальных платежей и банков;  
• без рекламы и подписок;  
• без сбора персональных данных и регистрации;  
• всё хранится на устройстве;  
• взрослый может посмотреть прогресс по коду ребёнка.

Основано на идеях Единой рамки компетенций финансовой грамотности. Играйте вместе — обсуждайте решения в реальной жизни без давления.

## Возрастная маркировка

**0+ / для детей** (контент спокойный, без насилия и реальных денег).  
Рекомендуемый возраст использования: **7–11 лет** при участии взрослого.
