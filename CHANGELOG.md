# Changelog

Все заметные изменения проекта «Питомец Финни» фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версия — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-24

### Добавлено

- Первый публичный прототип для хакатона / проверки.
- Выбор роли: ребёнок / родитель (код доступа).
- Создание питомца (9 визуальных комбинаций), стадии малыш → подросток → взрослый.
- Игровая экономика: бюджет, работа, еда, энергия, радость, налог, одежда по сезонам.
- Планирование бюджета (обязательные / необязательные / накопления).
- Накопления и 3 цели (1000 / 1500 / 2000).
- Задания и уроки по 3 темам финансовой грамотности.
- Раздел для взрослого с барьером и сбросом профиля.
- Демо-режим: 5 периодов подряд, ручной сезон, налог на 5-м периоде.
- Локальное хранение Room, офлайн-игра.
- Документация, тест-кейсы, материалы RuStore, презентация.
